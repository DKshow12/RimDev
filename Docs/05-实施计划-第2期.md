# RimDev 实施计划 · 第 2 期（Mod 目录 + Def 索引 + 静态体检）

> **For agentic workers:** REQUIRED SUB-SKILL: 按 Task 顺序执行，每个 Task 内按 `- [ ]` 逐步推进；**不要跳步、不要合并 Task**。每个 Task 末尾必须跑自测并看到期望输出。
> **铁律（第 1 期的血泪教训）**：计划里的「期望输出」与 C# 代码块，**没真跑过就只是假设**。第 1 期有 4 个"看起来合理、实际必失败"的缺陷是执行时才暴露的。因此本计划所有锚点都来自实测，且每个 Task 都必须 build + run。

**Goal:** 建立「磁盘上这份 XML 加载后会不会崩」的离线判定能力：把 3984 个 mod 目录编成目录表，按 RimWorld 的规则找出每个 mod 的目标版本 Def 文件，流式抽出全部 def 头建成索引，然后在索引上跑**结构一致性 + 字段名合法性**体检——让「字段名写错」「父类不存在」「defName 重名」「注释含 `--`」这类错误在不开游戏时就被拦下。

**Architecture:** 在 `RimDev.Core` 下新增 `Catalog`（mod 目录表 + 加载顺序）、`Defs`（流式扫描 + 索引 + 磁盘缓存）、`Checks`（规则实现）三块；`RimDev.Cli` 新增 `index` / `check` 子命令；`name check --kind def` 接上索引。**零外部 NuGet 依赖**（见 §0.3 关于放弃 SQLite 的决策）。

**Tech Stack:** 沿用第 1 期：C# 12 / .NET 8 / 手写 csproj / 自研断言台 `Harness.cs` / `System.Text.Json`。新增使用 `System.Xml.XmlReader`（BCL 自带）。

### 0.1 必须避开的坑：`packageId` 不是"文件里第一个 `<packageId>`"

**实测反例**（`workshop\content\294100\2538411704\About\About.xml`，Visual Exceptions）：

```xml
<ModMetaData>
  <name>Visual Exceptions</name>
  ...
  <modDependencies>
    <li>
      <packageId>brrainz.harmony</packageId>     <!-- ← 依赖，排在前面 -->
      ...
    </li>
  </modDependencies>
  <loadBefore><li>Ludeon.RimWorld</li></loadBefore>
  <loadAfter><li>brrainz.harmony</li></loadAfter>
  <packageId>brrainz.visualexceptions</packageId>  <!-- ← 自己的真实 id -->
</ModMetaData>
```

后果（实测对比同一个 3984 目录集合）：

| 提取方式 | 解析出的 mod 数 | 重复 packageId | 启用 mod 能否定位 |
|---|---|---|---|
| 「取第一个 `<packageId>`」正则 | 3714 | **257**（几乎全是 `brrainz.harmony`） | ❌ `brrainz.visualexceptions` 解析不到 |
| **XML 感知：只取 `<ModMetaData>` 的 depth==1 直接子元素** | **3971** | **0** | ✅ 17/17 |

**→ 必须用 XML 感知提取。** 代价只有 366 ms（1375 ms vs 1009 ms），完全可接受。
> 这与项目历史教训同源：**静态检查"跑通了"不等于"正确"**。错误的正则会让 7% 的 mod 认错 id，而报告看起来一切正常。

### 0.2 三条实现纪律（沿用第 1 期）

1. **字段名合法性检查必须复用第 1 期的 `MemberInfoIndex`**：字段枚举 = `Public|NonPublic|Instance`（**不含 Static**），大小写敏感，`MemberKind`→`NameKind` 需显式映射。
2. **行号必须保留**：`XmlReader` 的 `IXmlLineInfo` 给出 1-based 行列；诊断里没有行号等于没定位。
3. **诊断按稳定指纹去重**（第 1 期的 `Diagnostic.Fingerprint` 已具备）。

### 0.3 决策：**放弃 SQLite，改用 JSONL 索引**（对 `01` §9.1 的修订）

| 依据 | 说明 |
|---|---|
| SQLite 可用但会破坏"0 警告"纪律 | 实测 `Microsoft.Data.Sqlite 8.0.10` **能离线还原**（round-trip 通过），但 `PackageReference` 会触发 **`NU1900`（漏洞库拉取失败）警告 ×2**。第 1 期立的纪律是**构建必须 0 警告 0 错误**。 |
| 规模不需要数据库 | 启用集合只有 42 MB XML；全库 300 MB XML 抽出的 def 头索引估计 40–70 MB，**单文件 JSONL + 内存 Dictionary 完全够用**，且检索是内存哈希查找。 |
| 增量更新更简单 | 用一份 `fingerprints.json`（`path → size+mtime`）跳过未变文件，比 SQLite 事务更少出错面。 |
| 保留零依赖 | 与第 1 期一致，任何机器上 clone 即可 build。 |

> 若将来全库索引体积超过 ~300 MB 或需要外部工具查询，再引入 SQLite；届时须在 csproj 里加 `<NuGetAudit>false</NuGetAudit>` 以维持 0 警告。

```csharp
using System.Xml;

namespace RimDev.Core.Catalog;

/// <summary>&lt;About.xml&gt; 里我们需要的字段。</summary>
public sealed record AboutInfo(
    string PackageId,
    string DisplayName,
    string[] SupportedVersions,
    string[] Dependencies,
    string[] LoadAfter,
    string[] LoadBefore,
    string? Error);

/// <summary>
/// 读取 <c>About/About.xml</c>。
///
/// ★ 核心纪律：**只取 &lt;ModMetaData&gt; 的直接子元素**，不要用「文件里第一个 &lt;packageId&gt;」。
///
/// 实测反例（工坊 2538411704 Visual Exceptions）：它的 &lt;modDependencies&gt; 排在自身
/// &lt;packageId&gt; 之前，里面有 &lt;packageId&gt;brrainz.harmony&lt;/packageId&gt;。
/// 用正则取第一个会得到 brrainz.harmony —— 实测这会让 3984 个目录里 **257 个**认错 id
/// （7%），并让 brrainz.visualexceptions 这类 mod 完全解析不到目录。
/// XML 感知提取后：解析成功 3971 个、重复 0 个、17/17 启用 mod 全部定位。
/// 代价仅 1375 ms vs 1009 ms。
/// </summary>
public static class AboutXmlReader
{
    /// <summary>读取；失败时返回 Error 非空、PackageId 为空串的对象（不抛）。</summary>
    public static AboutInfo Read(string aboutPath)
    {
        try
        {
            var doc = new XmlDocument { XmlResolver = null };
            doc.Load(aboutPath);

            var root = doc.DocumentElement;
            if (root is null)
                return new AboutInfo("", "", Array.Empty<string>(), Array.Empty<string>(),
                    Array.Empty<string>(), Array.Empty<string>(), "About.xml 是空文档");

            // ★ 刻意【不检查根元素名】（IL 级实测证据）：
            //   全程序集扫描显示，Assembly-CSharp.dll 里含字面量 "ModMetaData" 的**方法数为 0**
            //   —— 若 RimWorld 比较过根元素名（如 xmlRoot.Name == "MetaData"），必然存在这个字面量。
            //   它只做 Path.Combine(modRoot, "About", "About.xml")（Verse.ModMetaData.Init 里有 "About"/"About.xml"），
            //   然后把 DocumentElement 交给字段映射——而字段映射只按【子元素名】取值。
            //   后果：实测有 **26 个**工坊 mod 的根元素写成小写 <modMetaData>，它们能被游戏正常加载；
            //   若在此做大小写敏感校验，会把这 26 个 mod 全部丢弃（3971 → 3945）。

            // ★ 关键：在**直接子节点**上取（XPath 的 child 轴）。
            //   不要用 GetElementsByTagName / XPath "//" / 正则——它们都会命中
            //   <modDependencies> 里的 <packageId>，实测会让 257 个 mod 认错 id。
            //   也刻意不嵌套 ReadSubtree()：子树嵌套的 depth 语义很脆，About.xml 只有 1–3 KB，
            //   用 DOM 直接读更简单也更不容易错。
            var packageId = DirectText(root, "packageId");
            var displayName = DirectText(root, "name");

            if (packageId.Length == 0)
                return new AboutInfo("", displayName, Array.Empty<string>(), Array.Empty<string>(),
                    Array.Empty<string>(), Array.Empty<string>(),
                    "About.xml 里没有直接的 <packageId> 子元素");

            return new AboutInfo(
                packageId,
                displayName,
                LiValues(root, "supportedVersions"),
                DependencyPackageIds(root),
                LiValues(root, "loadAfter"),
                LiValues(root, "loadBefore"),
                null);
        }
        catch (Exception ex)
        {
            return new AboutInfo("", "", Array.Empty<string>(), Array.Empty<string>(),
                Array.Empty<string>(), Array.Empty<string>(), $"{ex.GetType().Name}: {ex.Message}");
        }
    }

    /// <summary>取直接子元素（child 轴）的文本，不存在返回空串。</summary>
    private static string DirectText(XmlElement root, string childName)
        => root.SelectSingleNode(childName)?.InnerText?.Trim() ?? "";

    /// <summary>取 &lt;container&gt;&lt;li&gt;值&lt;/li&gt;…&lt;/container&gt;。</summary>
    private static string[] LiValues(XmlElement root, string containerName)
    {
        var container = root.SelectSingleNode(containerName);
        var nodes = container?.SelectNodes("li");
        if (nodes is null) return Array.Empty<string>();
        var list = new List<string>();
        foreach (XmlNode n in nodes)
        {
            var v = (n.InnerText ?? "").Trim();
            if (v.Length > 0) list.Add(v);
        }
        return list.ToArray();
    }

    /// <summary>取 &lt;modDependencies&gt;&lt;li&gt;&lt;packageId&gt;x&lt;/packageId&gt;&lt;/li&gt;…&lt;/modDependencies&gt;。</summary>
    private static string[] DependencyPackageIds(XmlElement root)
    {
        var container = root.SelectSingleNode("modDependencies");
        var nodes = container?.SelectNodes("li");
        if (nodes is null) return Array.Empty<string>();
        var list = new List<string>();
        foreach (XmlNode li in nodes)
        {
            var v = li.SelectSingleNode("packageId")?.InnerText?.Trim();
            if (!string.IsNullOrEmpty(v)) list.Add(v);
        }
        return list.ToArray();
    }
}
}
```

```csharp
using System.Xml;

namespace RimDev.Core.Catalog;

/// <summary>
/// 解析 <c>loadFolders.xml</c>，取出**目标版本**对应的目录列表。
///
/// 实测格式普查（3984 个目录）：<c>&lt;v1.6&gt;</c> = 1374 个，<c>&lt;1.6&gt;</c> = 0 个，
/// 有 loadFolders 但没有 1.6 键 = 48 个。因此以 <c>v</c>+版本 为主，同时兼容无 <c>v</c> 写法。
/// 目录值 <c>/</c> 表示 mod 根。
/// </summary>
public static class LoadFoldersReader
{
    /// <summary>
    /// 返回目标版本对应的目录列表（**已过滤掉磁盘上不存在的目录**）。
    /// 没有 loadFolders.xml 时返回 null，调用方按回落规则处理。
    /// </summary>
    public static string[]? Read(string modRoot, string targetVersion)
    {
        var path = FindLoadFolders(modRoot);
        if (path is null) return null;

        try
        {
            var doc = new XmlDocument { XmlResolver = null };
            doc.Load(path);

            var keys = new[] { "v" + targetVersion, targetVersion };
            XmlNode? section = null;
            foreach (var k in keys)
            {
                section = doc.DocumentElement?.SelectSingleNode(k);
                if (section is not null) break;
            }
            if (section is null) return Array.Empty<string>();

            var result = new List<string>();
            foreach (XmlNode li in section.SelectNodes("li") ?? new XmlNodeListStub())
            {
                var v = (li.InnerText ?? "").Trim();
                if (v.Length == 0) continue;
                if (v == "/" || v == "." || v == "\\")
                {
                    result.Add(modRoot);
                    continue;
                }
                var abs = Path.Combine(modRoot, v.Replace('/', Path.DirectorySeparatorChar));
                if (Directory.Exists(abs)) result.Add(abs);
            }
            return result.ToArray();
        }
        catch
        {
            return Array.Empty<string>();
        }
    }

    /// <summary>工坊 mod 里两种拼写都见过（loadFolders.xml / LoadFolders.xml）。</summary>
    public static string? FindLoadFolders(string modRoot)
    {
        foreach (var n in new[] { "loadFolders.xml", "LoadFolders.xml" })
        {
            var p = Path.Combine(modRoot, n);
            if (File.Exists(p)) return p;
        }
        return null;
    }

    /// <summary>没有 loadFolders.xml 时的回落：有 &lt;root&gt;\&lt;targetVersion&gt; 就用它 + 根，否则只用根。</summary>
    public static string[] Fallback(string modRoot, string targetVersion)
    {
        var versioned = Path.Combine(modRoot, targetVersion);
        return Directory.Exists(versioned)
            ? new[] { modRoot, versioned }
            : new[] { modRoot };
    }

    /// <summary>
    /// 空集合占位。★ 必须继承 <see cref="XmlNodeList"/>：
    /// <c>section.SelectNodes("li") ?? new XmlNodeListStub()</c> 要求 <c>??</c> 两侧类型兼容，
    /// 若占位类只实现 IEnumerable，会得到 **CS0019（运算符 ?? 无法应用于 XmlNodeList 和 Stub）**。
    /// （此缺陷由第 2 期 Task 1 执行者在编译时发现并按本语义修复。）
    /// </summary>
    private sealed class XmlNodeListStub : XmlNodeList
    {
        public override XmlNode? Item(int index) => null;
        public override int Count => 0;
        public override System.Collections.IEnumerator GetEnumerator()
            => Enumerable.Empty<XmlNode>().GetEnumerator();
    }
}
```

```csharp
using RimDev.Core.Diagnostics;
using RimDev.Core.Environment;

namespace RimDev.Core.Catalog;

public sealed record CatalogBuildResult(
    ModCatalog Catalog,
    IReadOnlyList<Diagnostic> Diagnostics,
    long ElapsedMs);

/// <summary>
/// 扫描所有 mod 目录并建立 packageId → ModInfo 的目录表。
///
/// 实测规模：3984 个候选目录（本地 Mods 11 + 官方 Data 6 + 工坊 3967），
/// XML 感知扫描耗时 1375 ms，解析出 3971 个 packageId、0 个真实重复。
/// 因此**元数据层不缓存**——每次运行直接扫。
///
/// 同 packageId 冲突时按 Official &gt; Local &gt; Workshop 优先级保留先者，
/// 后者记为被遮蔽（报 RD1005）。
/// </summary>
public sealed class ModCatalog
{
    private readonly Dictionary<string, ModInfo> _byPackageId;

    private ModCatalog(IReadOnlyList<ModInfo> all, IReadOnlyList<ModInfo> active,
        Dictionary<string, ModInfo> byPackageId)
    {
        All = all;
        Active = active;
        _byPackageId = byPackageId;
    }

    public IReadOnlyList<ModInfo> All { get; }
    public IReadOnlyList<ModInfo> Active { get; }
    public bool TryGet(string packageId, out ModInfo mod) => _byPackageId.TryGetValue(packageId, out mod!);
    public ModInfo? Get(string packageId) => _byPackageId.GetValueOrDefault(packageId);

    public static CatalogBuildResult Build(GameEnv env, string targetVersion,
        IReadOnlyList<string> activePackageIds)
    {
        var sw = System.Diagnostics.Stopwatch.StartNew();
        var diagnostics = new List<Diagnostic>();
        var candidates = EnumerateCandidates(env);

        var byPkg = new Dictionary<string, ModInfo>(StringComparer.OrdinalIgnoreCase);
        var all = new List<ModInfo>();

        foreach (var (root, source) in candidates)
        {
            var about = Path.Combine(root, "About", "About.xml");
            var hasAbout = File.Exists(about);

            string packageId;
            AboutInfo aboutInfo = new("", "", Array.Empty<string>(), Array.Empty<string>(),
                Array.Empty<string>(), Array.Empty<string>(), null);

            if (hasAbout)
            {
                aboutInfo = AboutXmlReader.Read(about);
                packageId = aboutInfo.PackageId;
                if (string.IsNullOrWhiteSpace(packageId))
                {
                    // 无 packageId 的目录不进目录表（实测 13 个，多为无 About 的杂项目录）
                    continue;
                }
            }
            else
            {
                continue;   // 没有 About.xml 就不是 mod
            }

            var folders = LoadFoldersReader.Read(root, targetVersion)
                          ?? LoadFoldersReader.Fallback(root, targetVersion);

            var info = new ModInfo(
                PackageId: packageId,
                DisplayName: aboutInfo.DisplayName,
                RootPath: root,
                Source: source,
                PublishedFileId: source == ModSource.Workshop ? Path.GetFileName(root) : null,
                SupportedVersions: aboutInfo.SupportedVersions,
                LoadFolders: folders,
                Dependencies: aboutInfo.Dependencies,
                LoadAfter: aboutInfo.LoadAfter,
                LoadBefore: aboutInfo.LoadBefore,
                IsActive: activePackageIds.Contains(packageId, StringComparer.OrdinalIgnoreCase),
                HasAssemblies: Directory.Exists(Path.Combine(root, "Assemblies")),
                AboutPath: hasAbout ? about : null,
                AboutError: aboutInfo.Error);

            if (byPkg.TryGetValue(packageId, out var existing))
            {
                // 实测本机 0 例；保留逻辑以备用户环境不同
                var winner = existing.Source.Priority() <= source.Priority() ? existing : info;
                var loser = ReferenceEquals(winner, existing) ? info : existing;
                if (!ReferenceEquals(winner, existing))
                {
                    byPkg[packageId] = winner;
                    all.Remove(existing);
                    all.Add(winner);
                    all.Add(loser);
                }
                else
                {
                    all.Add(loser);
                }
                diagnostics.Add(new Diagnostic(Codes.DuplicatePackageId, Severity.Warning, Scope.Offline,
                    $"packageId 重复：{packageId}",
                    $"保留 {winner.RootPath}，遮蔽 {loser.RootPath}",
                    TypeName: packageId,
                    Evidence: new Dictionary<string, string>
                    {
                        ["kept"] = winner.RootPath,
                        ["shadowed"] = loser.RootPath
                    }));
                continue;
            }

            byPkg[packageId] = info;
            all.Add(info);
        }

        sw.Stop();
        var active = all.Where(m => m.IsActive).ToList();
        var catalog = new ModCatalog(all, active, byPkg);
        return new CatalogBuildResult(catalog, diagnostics, sw.ElapsedMilliseconds);
    }

    /// <summary>本地 Mods\ + 官方 Data\ + 工坊。注意 <c>_rimdev</c> 也在 Mods 下，但无 About.xml 会被跳过。</summary>
    public static IEnumerable<(string Root, ModSource Source)> EnumerateCandidates(GameEnv env)
    {
        if (Directory.Exists(env.ModsDir))
            foreach (var d in Directory.GetDirectories(env.ModsDir))
                yield return (d, ModSource.Local);

        if (Directory.Exists(env.DataDir))
            foreach (var d in Directory.GetDirectories(env.DataDir))
                yield return (d, ModSource.Official);

        if (Directory.Exists(env.WorkshopDir))
            foreach (var d in Directory.GetDirectories(env.WorkshopDir))
                yield return (d, ModSource.Workshop);
    }

    /// <summary>从 ModsConfig.xml 只取 &lt;activeMods&gt; 段（★ 不能扫全文的 &lt;li&gt;，那会混进 knownExpansions）。</summary>
    public static string[] ReadActiveMods(string modsConfigPath)
    {
        if (!File.Exists(modsConfigPath)) return Array.Empty<string>();
        var text = File.ReadAllText(modsConfigPath);
        var m = System.Text.RegularExpressions.Regex.Match(text,
            @"(?s)<activeMods>(.*?)</activeMods>");
        if (!m.Success) return Array.Empty<string>();
        return System.Text.RegularExpressions.Regex.Matches(m.Groups[1].Value, @"<li>([^<]+)</li>")
            .Select(x => x.Groups[1].Value.Trim())
            .Where(x => x.Length > 0)
            .ToArray();
    }
}
```

Create `_rimdev\engine\RimDev.Core\Defs\DefScanner.cs`：

```csharp
using System.Xml;

namespace RimDev.Core.Defs;

public sealed record DefFileResult(
    string FileAbs,
    string ModPackageId,
    IReadOnlyList<RawDef> Defs,
    string? ParseError,
    int? ErrorLine,
    int? ErrorColumn,
    bool CommentHasDoubleDash);

public sealed record ScanResult(
    IReadOnlyList<RawDef> Defs,
    IReadOnlyList<DefFileResult> Files,
    int FilesScanned,
    int FilesFailed,
    long ElapsedMs);

/// <summary>
/// 流式扫描 Defs/*.xml，只抽取 def 头，**不把 XML 装进 DOM**（全库 300 MB，必须流式）。
///
/// 两个必须遵守的点：
/// 1. **保留行号**：用 <see cref="IXmlLineInfo"/>（XmlReader 实现了它）。没有行号的诊断等于没定位。
/// 2. **注释含 `--` 要单独报**：XmlReader 遇到 `--` 会直接抛 XmlException，且**报错位置与真实问题行无关**
///    （项目历史：4 次踩坑，3 次是表格分隔线 `|------|`）。所以解析失败时再跑一次廉价的逐行预扫，
///    把「注释含 --」与「其它语法错」区分开（RD2002 vs RD2001）。
/// </summary>
public static class DefScanner
{
    public static ScanResult Scan(IEnumerable<(string FileAbs, string ModPackageId, string ModRoot)> files)
    {
        var sw = System.Diagnostics.Stopwatch.StartNew();
        var allDefs = new List<RawDef>();
        var results = new List<DefFileResult>();
        int failed = 0;

        foreach (var (fileAbs, pkgId, modRoot) in files)
        {
            var r = ScanFile(fileAbs, pkgId, modRoot);
            results.Add(r);
            if (r.ParseError is not null) failed++;
            allDefs.AddRange(r.Defs);
        }

        sw.Stop();
        return new ScanResult(allDefs, results, results.Count, failed, sw.ElapsedMilliseconds);
    }

    public static DefFileResult ScanFile(string fileAbs, string modPackageId, string modRoot)
    {
        var defs = new List<RawDef>();
        string rel = Path.GetRelativePath(modRoot, fileAbs);
        string? parseError = null;
        int? errLine = null, errCol = null;

        try
        {
            using var stream = File.OpenRead(fileAbs);
            using var reader = XmlReader.Create(stream, new XmlReaderSettings
            {
                IgnoreComments = true,
                IgnoreWhitespace = true,
                DtdProcessing = DtdProcessing.Prohibit
            });

            var li = (IXmlLineInfo)reader;
            string? rootSeen = null;

            // ★ 单遍深度跟踪，**不嵌套 ReadSubtree**：
            //   ReadSubtree 的 Depth 语义很容易读错（子树根到底是 0 还是原深度），而且一旦判错
            //   就会【静默产错】（defName 全为 null）而不是编译报错——这类错误最贵。
            //   这里用显式的 pending 状态：Depth==1 是 def 开始，Depth==2 的 <defName> 是它的名字，
            //   Depth==1 的 EndElement 是 def 结束。
            RawDef? pending = null;
            string? pendingDefName = null;
            bool pendingAbstract = false;

            void Emit()
            {
                if (pending is null) return;
                var name = string.IsNullOrWhiteSpace(pendingDefName) ? null : pendingDefName;
                defs.Add(pending with
                {
                    DefName = name,
                    IsAbstract = pendingAbstract || (pending.NameAttr is not null && name is null)
                });
                pending = null;
                pendingDefName = null;
                pendingAbstract = false;
            }

            while (reader.Read())
            {
                var line = li.HasLineInfo() ? li.LineNumber : 0;

                if (reader.NodeType == XmlNodeType.Element)
                {
                    if (rootSeen is null)
                    {
                        rootSeen = reader.Name;
                        if (rootSeen != "Defs")
                        {
                            // ★★ <Patch> 是**合法的 RimWorld 补丁文件**（Defs 与 Patches 都要枚举），
                            //   不能当成解析失败——否则「解析失败 = 0」在任何含 patch 的环境下都不可能成立。
                            //   但也不能直接 break：必须读完剩余内容，才能发现「根对、正文坏」的文件
                            //  （实测第一次修成这样时，坏 Patch 会被静默放过，RD2001 能力就丢了）。
                            rootKind = rootSeen;
                            try { while (reader.Read()) { } }
                            catch (XmlException ex2)
                            {
                                parseError = $"XmlException: {ex2.Message}";
                                errLine = ex2.LineNumber > 0 ? ex2.LineNumber : null;
                                errCol = ex2.LinePosition > 0 ? ex2.LinePosition : null;
                            }
                            break;
                        }
                        rootKind = "Defs";
                        continue;
                    }

                    if (reader.Depth == 1)
                    {
                        // 一个 def 的开始
                        var nameAttr = reader.GetAttribute("Name");
                        var parentName = reader.GetAttribute("ParentName");
                        var mayRequire = reader.GetAttribute("MayRequire");
                        pendingAbstract = string.Equals(reader.GetAttribute("Abstract"), "True",
                            StringComparison.OrdinalIgnoreCase);
                        pendingDefName = null;
                        pending = new RawDef(
                            DefType: reader.Name,
                            DefName: null,                        // 稍后由子元素补上
                            NameAttr: string.IsNullOrWhiteSpace(nameAttr) ? null : nameAttr,
                            ParentName: string.IsNullOrWhiteSpace(parentName) ? null : parentName,
                            MayRequire: string.IsNullOrWhiteSpace(mayRequire) ? null : mayRequire,
                            IsAbstract: pendingAbstract,           // Emit 时再按 Name=/defName 复合判断
                            ModPackageId: modPackageId,
                            FileAbs: fileAbs,
                            FileRelToMod: rel,
                            Line: line);

                        if (reader.IsEmptyElement) Emit();    // 空 def 节点：只有属性
                        continue;
                    }

                    if (pending is not null && reader.Depth == 2
                        && reader.Name == "defName" && pendingDefName is null)
                    {
                        // 只取 def 的一级子元素 <defName>；comps/li 里同名的不会命中（Depth 不同）
                        pendingDefName = reader.ReadElementContentAsString().Trim();
                        // ★★ ReadElementContentAsString 会把**父元素（本 def）的结束标签一起消费掉**。
                        //   若 <defName> 恰好是本 def 的最后一个子元素（原版大量 def 正是这个形状），
                        //   depth==1 的 EndElement 就永远看不到 → 该 def 被【静默丢弃】（不报错、不变红）。
                        //   实测：不加这一句，1649 个文件里 18 个文件的 def 数偏少（DOM 真值 14480 vs 扫描 14372）。
                        if (reader.Depth <= 1) Emit();
                        continue;
                    }

                    continue;
                }

                if (reader.NodeType == XmlNodeType.EndElement && reader.Depth == 1 && pending is not null)
                    Emit();
            }

            Emit();   // 兜底：文件末尾未见 EndElement 时也不丢最后一个 def
            }
        }
        catch (XmlException ex)
        {
            parseError = $"XmlException: {ex.Message}";
            errLine = ex.LineNumber > 0 ? ex.LineNumber : (int?)null;
            errCol = ex.LinePosition > 0 ? ex.LinePosition : (int?)null;
        }
        catch (Exception ex)
        {
            parseError = $"{ex.GetType().Name}: {ex.Message}";
        }

        // 解析失败时判断是不是「注释含 --」——这决定了报 RD2002 还是 RD2001
        bool dash = false;
        if (parseError is not null) dash = CommentHasDoubleDash(fileAbs);

        return new DefFileResult(fileAbs, modPackageId, defs, parseError, errLine, errCol, dash);
    }

    /// <summary>
    /// 廉价预扫：逐行找 &lt;!-- ... --&gt; 区间内是否含 `--`。
    /// 只在解析失败时调用（全库 300 MB，不能每次都跑）。
    /// </summary>
    public static bool CommentHasDoubleDash(string fileAbs)
    {
        try
        {
            var text = File.ReadAllText(fileAbs);
            int i = 0;
            while (true)
            {
                var open = text.IndexOf("<!--", i, StringComparison.Ordinal);
                if (open < 0) return false;
                var close = text.IndexOf("-->", open + 4, StringComparison.Ordinal);
                if (close < 0) return false;
                var body = text.Substring(open + 4, close - open - 4);
                if (body.Contains("--", StringComparison.Ordinal)) return true;
                i = close + 3;
            }
        }
        catch
        {
            return false;
        }
    }

    /// <summary>枚举一个 mod 的 Defs 与 Patches 目录下的所有 .xml。</summary>
    public static IEnumerable<string> EnumerateXmlFiles(ModInfoLike mod)
    {
        foreach (var dir in mod.LoadFolders)
        {
            foreach (var sub in new[] { "Defs", "Patches" })
            {
                var p = Path.Combine(dir, sub);
                if (!Directory.Exists(p)) continue;
                foreach (var f in Directory.EnumerateFiles(p, "*.xml", SearchOption.AllDirectories))
                    yield return f;
            }
        }
    }

    /// <summary>避免 Core.Defs 直接依赖 Core.Catalog 的具体类型（保持单向）。</summary>
    public interface ModInfoLike
    {
        string PackageId { get; }
        string RootPath { get; }
        IReadOnlyList<string> LoadFolders { get; }
    }
}
```

```csharp
namespace RimDev.Core.Defs;

/// <summary>
/// defName → 声明处列表（RimWorld 的 defName 是**全局唯一**的，所以同名即冲突）。
/// <c>Name=</c> 的抽象基类走独立的抽象命名空间，两者不能互相引用。
/// </summary>
public sealed class DefIndex
{
    public Dictionary<string, List<RawDef>> ByDefName { get; } = new(StringComparer.Ordinal);
    public Dictionary<string, List<RawDef>> ByAbstractName { get; } = new(StringComparer.Ordinal);
    public Dictionary<string, int> CountByType { get; } = new(StringComparer.Ordinal);
    public int TotalDefs { get; private set; }
    public int AbstractDefs { get; private set; }

    public static DefIndex Build(IEnumerable<RawDef> defs)
    {
        var idx = new DefIndex();
        foreach (var d in defs)
        {
            idx.TotalDefs++;
            idx.CountByType[d.DefType] = idx.CountByType.GetValueOrDefault(d.DefType) + 1;

            if (!string.IsNullOrEmpty(d.DefName))
            {
                if (!idx.ByDefName.TryGetValue(d.DefName, out var l))
                    idx.ByDefName[d.DefName] = l = new List<RawDef>();
                l.Add(d);
            }
            if (!string.IsNullOrEmpty(d.NameAttr))
            {
                idx.AbstractDefs++;
                if (!idx.ByAbstractName.TryGetValue(d.NameAttr, out var l))
                    idx.ByAbstractName[d.NameAttr] = l = new List<RawDef>();
                l.Add(d);
            }
        }
        return idx;
    }

    public bool IsDefNameTaken(string name) => ByDefName.ContainsKey(name);
    public bool IsAbstractNameTaken(string name) => ByAbstractName.ContainsKey(name);

    /// <summary>defName 或抽象名都可作为 ParentName 的目标。</summary>
    public bool CanBeReferenced(string name) => IsDefNameTaken(name) || IsAbstractNameTaken(name);
}
```

```csharp
namespace RimDev.Core.Defs;

/// <summary>文件指纹，用于增量跳过未变文件（实测启用集合 1649 文件，全量重扫实测 185 ms）。</summary>
public sealed record FileFingerprint(long Size, long MtimeUtcTicks);

// ★ Task 4b 已从交付代码中删除：全仓无引用（Task 5 的统计是内联算的），属死代码。
// public sealed record StoreStats(int FilesLoaded, int FilesSkippedByCache, int DefsLoaded, long ElapsedMs);

/// <summary>
/// 索引的磁盘形态：一个 JSONL（每行一个 def 头）+ 一个 JSON 指纹表。
///
/// 为什么不用 SQLite：本机 nuget.org 不可达，SQLite 只能靠本地缓存（8.0.10 确实可用），
/// 但引入 PackageReference 会触发 NU1900（漏洞库拉取失败）警告，破坏「构建 0 警告」纪律。
/// 实测规模（启用集合 12.91 MB / 1649 个 XML、全库 299.94 MB）下，JSONL + 内存 Dictionary 足够。
/// ★ 更正（2026-10-14）：此前写「启用集合 41.83 MB XML」是**错误测量**（与已作废的 6340 同源），
///   权威值 = 13,537,807 B / 12.91 MB，已与 1649 一起由两路独立枚举交叉验证。
/// 见实施计划 §0.3。
/// </summary>
public sealed class DefIndexStore
{
    private readonly string _dir;

    public DefIndexStore(string dir) => _dir = dir;

    public string DefsPath => Path.Combine(_dir, "defs.jsonl");
    public string FingerprintsPath => Path.Combine(_dir, "fingerprints.json");
    public string MetaPath => Path.Combine(_dir, "index-meta.json");

    private static readonly JsonSerializerOptions Json = new() { WriteIndented = false };

    public Dictionary<string, FileFingerprint> LoadFingerprints()
    {
        if (!File.Exists(FingerprintsPath)) return new Dictionary<string, FileFingerprint>(StringComparer.OrdinalIgnoreCase);
        try
        {
            var text = File.ReadAllText(FingerprintsPath);
            return JsonSerializer.Deserialize<Dictionary<string, FileFingerprint>>(text)
                   ?? new Dictionary<string, FileFingerprint>(StringComparer.OrdinalIgnoreCase);
        }
        catch
        {
            return new Dictionary<string, FileFingerprint>(StringComparer.OrdinalIgnoreCase);
        }
    }

    public static FileFingerprint Fingerprint(string fileAbs)
    {
        var fi = new FileInfo(fileAbs);
        return new FileFingerprint(fi.Length, fi.LastWriteTimeUtc.Ticks);
    }

    /// <summary>把扫描结果写成 JSONL（覆盖写），同时写指纹表与元信息。</summary>
    public void Save(ScanResult scan, IReadOnlyDictionary<string, FileFingerprint> fingerprints, string scopeNote)
    {
        Directory.CreateDirectory(_dir);

        using (var w = new StreamWriter(DefsPath, false, new UTF8Encoding(false)))
        {
            foreach (var d in scan.Defs)
            {
                w.WriteLine(JsonSerializer.Serialize(new
                {
                    t = d.DefType,
                    n = d.DefName,
                    a = d.NameAttr,
                    p = d.ParentName,
                    m = d.MayRequire,
                    x = d.IsAbstract,
                    mod = d.ModPackageId,
                    f = d.FileAbs,
                    r = d.FileRelToMod,
                    l = d.Line
                }, Json));
            }
        }

        File.WriteAllText(FingerprintsPath, JsonSerializer.Serialize(fingerprints, Json));
        File.WriteAllText(MetaPath, JsonSerializer.Serialize(new
        {
            schemaVersion = 1,
            scope = scopeNote,
            files = scan.FilesScanned,
            failed = scan.FilesFailed,
            defs = scan.Defs.Count,
            savedAtUtc = DateTime.UtcNow.ToString("o")
        }, new JsonSerializerOptions { WriteIndented = true }));
    }

    /// <summary>读回索引。用于后续 check / name --kind def 免重扫。</summary>
    public List<RawDef> LoadDefs()
    {
        var list = new List<RawDef>();
        if (!File.Exists(DefsPath)) return list;

        foreach (var line in File.ReadLines(DefsPath))
        {
            if (line.Length == 0) continue;
            using var doc = JsonDocument.Parse(line);
            var r = doc.RootElement;
            list.Add(new RawDef(
                DefType: r.GetProperty("t").GetString() ?? "",
                DefName: r.GetProperty("n").GetString(),
                NameAttr: r.GetProperty("a").GetString(),
                ParentName: r.GetProperty("p").GetString(),
                MayRequire: r.GetProperty("m").GetString(),
                IsAbstract: r.GetProperty("x").GetBoolean(),
                ModPackageId: r.GetProperty("mod").GetString() ?? "",
                FileAbs: r.GetProperty("f").GetString() ?? "",
                FileRelToMod: r.GetProperty("r").GetString() ?? "",
                Line: r.GetProperty("l").GetInt32()));
        }
        return list;
    }

    /// <summary>挑出需要重新解析的文件（指纹变了或不在缓存里）。</summary>
    public static List<(string FileAbs, string ModPackageId, string ModRoot)> SelectChanged(
        IReadOnlyList<(string FileAbs, string ModPackageId, string ModRoot)> all,
        IReadOnlyDictionary<string, FileFingerprint> cache)
    {
        var changed = new List<(string, string, string)>();
        foreach (var f in all)
        {
            if (!File.Exists(f.FileAbs)) continue;
            if (cache.TryGetValue(f.FileAbs, out var fp) && fp == Fingerprint(f.FileAbs)) continue;
            changed.Add(f);
        }
        return changed;
    }

    public static Dictionary<string, FileFingerprint> FingerprintAll(
        IReadOnlyList<(string FileAbs, string ModPackageId, string ModRoot)> all)
    {
        var d = new Dictionary<string, FileFingerprint>(StringComparer.OrdinalIgnoreCase);
        foreach (var f in all)
            if (File.Exists(f.FileAbs)) d[f.FileAbs] = Fingerprint(f.FileAbs);
        return d;
    }

    public bool Exists() => File.Exists(DefsPath) && File.Exists(MetaPath);
}
```

```csharp
using RimDev.Core.Diagnostics;

namespace RimDev.Core.Checks;

public sealed class CheckRunner
{
    private readonly List<ICheck> _checks = new();

    public CheckRunner Add(ICheck check) { _checks.Add(check); return this; }

    public static CheckRunner Default()
    {
        return new CheckRunner()
            .Add(new XmlWellFormedCheck())
            .Add(new CommentDashCheck())
            .Add(new DuplicateDefNameCheck())
            .Add(new ParentChainCheck())
            .Add(new FieldNameCheck());
    }

    public IReadOnlyList<Diagnostic> Run(CheckContext ctx, Func<Diagnostic, bool>? filter = null)
    {
        var all = new List<Diagnostic>();
        foreach (var c in _checks)
        {
            try { all.AddRange(c.Run(ctx)); }
            catch (Exception ex)
            {
                all.Add(new Diagnostic("RD9999", Severity.Error, Scope.Offline,
                    $"规则 {c.Id} 自身抛异常：{ex.GetType().Name}: {ex.Message}"));
            }
        }
        if (filter is not null) all = all.Where(filter).ToList();

        // ★ 按稳定指纹去重：同一处问题只报一条，附出现次数
        // （第 1 期实测：一次启动会加载两遍 Def，同一错误重复出现）
        return all
            .GroupBy(d => d.Fingerprint, StringComparer.Ordinal)
            .Select(g =>
            {
                var first = g.First();
                if (g.Count() == 1) return first;
                return first with
                {
                    Evidence = (first.Evidence ?? new Dictionary<string, string>())
                        .Concat(new[] { new KeyValuePair<string, string>("occurrences", g.Count().ToString()) })
                        .ToDictionary(kv => kv.Key, kv => kv.Value)
                };
            })
            .OrderByDescending(d => d.Severity)
            .ToList();
    }
}
```

```csharp
/// 同 defName 多次声明时，后者覆盖前者；被遮蔽的那份内容会静默丢失——

        {
            if (defs.Count < 2) continue;

            var first = defs[0];
```

```csharp
using RimDev.Core.Diagnostics;

namespace RimDev.Core.Checks;

/// <summary>
/// ParentName 链校验：父类不存在（RD2005）、继承环（RD2006）。
///
/// 两个易误报点（项目历史坑）：
/// 1. 原版抽象基类用 **`Name="X"` 属性**定义（如 &lt;ThingDef ParentName="BuildingBase" Name="Fleshmass"&gt;），
///    不是 &lt;defName&gt;。只按 defName 建索引会把 BaseBullet / BaseGun / BuildingBase 全判成"缺失"。
///    所以查找顺序是：先在 defName 空间找，再在抽象名空间找。
/// 2. 父类可能来自**未启用**的 mod。本检查只判"整个目录表里有没有"，
///    严格模式（只认启用集合）留给第 3 期。
/// </summary>
public sealed class ParentChainCheck : ICheck
{
    public string Id => Codes.ParentNotFound;

    public IEnumerable<Diagnostic> Run(CheckContext ctx)
    {
        foreach (var d in ctx.Defs)
        {
            if (string.IsNullOrEmpty(d.ParentName)) continue;

            if (!ctx.Index.CanBeReferenced(d.ParentName))
            {
                var suggestions = SuggestParent(ctx, d.ParentName);
                yield return new Diagnostic(
                    Codes.ParentNotFound, Severity.Error, Scope.Offline,
                    $"ParentName=\"{d.ParentName}\" 指向不存在的 def/抽象基类",
                    "检查拼写；原版抽象基类用 Name=\"X\" 定义，只能在抽象名空间里找到",
                    FileAbs: d.FileAbs, Line: d.Line,
                    ModPackageId: d.ModPackageId, DefName: d.DefName, DefType: d.DefType,
                    Suggestions: suggestions);
                continue;
            }

            if (HasCycle(ctx, d, out var chain))
            {
                yield return new Diagnostic(
                    Codes.InheritanceCycle, Severity.Error, Scope.Offline,
                    $"ParentName 继承环：{string.Join(" → ", chain)}",
                    "打断环，让链最终落到一个不带 ParentName 的基类",
                    FileAbs: d.FileAbs, Line: d.Line,
                    ModPackageId: d.ModPackageId, DefName: d.DefName, DefType: d.DefType);
            }
        }
    }

    private static bool HasCycle(CheckContext ctx, RawDef start, out List<string> chain)
    {
        chain = new List<string>();
        var seen = new HashSet<string>(StringComparer.Ordinal);
        var cur = start;
        while (cur is not null && !string.IsNullOrEmpty(cur.ParentName))
        {
            var key = cur.ReferableName ?? cur.FileAbs + ":" + cur.Line;
            if (!seen.Add(key)) { chain.Add(key); return true; }

            var parent = ctx.Index.ByDefName.GetValueOrDefault(cur.ParentName)?.FirstOrDefault()
                         ?? ctx.Index.ByAbstractName.GetValueOrDefault(cur.ParentName)?.FirstOrDefault();
            if (parent is null) return false;
            chain.Add(parent.ReferableName ?? parent.FileAbs + ":" + parent.Line);
            cur = parent;
        }
        return false;
    }

    private static List<string> SuggestParent(CheckContext ctx, string parentName)
    {
        var pool = ctx.Index.ByDefName.Keys.Concat(ctx.Index.ByAbstractName.Keys).Distinct();
        return pool
            .Select(n => (n, s: RimDev.Core.Metadata.MemberInfoIndex.Similarity(parentName, n)))
            .Where(x => x.s > 0)
            .OrderByDescending(x => x.s)
            .Take(5)
            .Select(x => x.n)
            .ToList();
    }
}
```

```csharp
using System.Xml;
using RimDev.Core.Defs;
using RimDev.Core.Diagnostics;
using RimDev.Core.Metadata;

namespace RimDev.Core.Checks;

/// <summary>
/// ★ 本期最有价值的一条：把 XML 元素名对着目标 Def 类的**真实字段表**校验。
///
/// 动机（项目历史）：静态校验（XML 良构 + defName 去重）**永远查不出「字段名不存在」**。
/// 本项目 10 类加载期错误里 6 类是名字不存在，而当时静态校验全绿。
/// 例：canBeDamagedByExplosions / canBeDeconstructed / deconstructibleBlocks 三个字段
/// 在程序集里**根本不存在**，却写成 XML 后被游戏报"doesn't correspond to any field"。
///
/// 实现要点：
///  - 复用 <see cref="MemberInfoIndex"/>：字段枚举 = Public|NonPublic|Instance（不含 Static），
///    大小写敏感。★ 这一条不能改：VerbProperties.forcedMissRadius 是 private 字段但合法。
///  - 只校验**能确定目标 C# 类型**的 def（DefType 名能解析成 Managed 里的类型）；
///    解析不到的报 RD2017（info）而不是当作错误。
///  - 只校验**顶层字段与一级子元素**：`<comps><li Class="...">` 这类多态节点的内层字段
///    需要按 Class 分派，属第 3 期。
/// </summary>
public sealed class FieldNameCheck : ICheck
{
    public string Id => Codes.FieldNotFound;

    public IEnumerable<Diagnostic> Run(CheckContext ctx)
    {
        ManagedAssemblyCatalog? catalog = null;
        try { catalog = ManagedAssemblyCatalog.Load(ReadManagedDir()); }
        catch { yield break; }   // 元数据不可用时静默跳过（v1 已有独立命令覆盖该场景）

        foreach (var d in ctx.Defs)
        {
            if (ctx.TargetModPackageId is not null && d.ModPackageId != ctx.TargetModPackageId) continue;

            var type = catalog.Find(d.DefType);
            if (type is null)
            {
                yield return new Diagnostic(Codes.UnknownDefType, Severity.Info, Scope.Offline,
                    $"Def 类型 `{d.DefType}` 在 Managed 里找不到对应 C# 类型，字段名校验被跳过",
                    "自定义 Def 类型需要 mod 自己的程序集；本期只校验原版类型",
                    FileAbs: d.FileAbs, Line: d.Line,
                    ModPackageId: d.ModPackageId, DefName: d.DefName, DefType: d.DefType);
                continue;
            }

            var members = catalog.MembersOf(type);
            foreach (var (elementName, line) in ReadTopLevelElements(d.FileAbs, d.Line))
            {
                if (elementName is "defName" or "ParentName" or "Name" or "Abstract" or "MayRequire") continue;
                if (members.FindField(elementName) is not null) continue;
                if (members.FindProperty(elementName) is not null) continue;

                var suggestions = members.Suggest(elementName, 5);
                var caseOnly = suggestions.FirstOrDefault(s => string.Equals(s, elementName, StringComparison.OrdinalIgnoreCase));
                yield return new Diagnostic(
                    caseOnly is not null ? Codes.CaseMismatch : Codes.FieldNotFound,
                    Severity.Error, Scope.Offline,
                    $"{d.DefType} 上没有字段 `{elementName}`",
                    caseOnly is not null ? $"大小写不符，正确写法是 {caseOnly}" : "用候选名替换",
                    FileAbs: d.FileAbs, Line: line,
                    ModPackageId: d.ModPackageId, DefName: d.DefName, DefType: d.DefType,
                    Suggestions: suggestions,
                    Evidence: new Dictionary<string, string>
                    {
                        ["defTypeFullName"] = type.FullName ?? type.Name,
                        ["publicFields"] = members.PublicFieldCount.ToString(),
                        ["allFields"] = members.AllFieldCount.ToString()
                    });
            }
        }
    }

    /// <summary>读某个 def（从 startLine 起）的一级子元素名与行号。</summary>
    internal static List<(string Name, int Line)> ReadTopLevelElements(string fileAbs, int startLine)
    {
        var list = new List<(string, int)>();
        try
        {
            using var stream = File.OpenRead(fileAbs);
            using var reader = XmlReader.Create(stream, new XmlReaderSettings
            {
                IgnoreComments = true, IgnoreWhitespace = true, DtdProcessing = DtdProcessing.Prohibit
            });
            var li = (IXmlLineInfo)reader;
            var defDepth = -1;
            while (reader.Read())
            {
                if (reader.NodeType != XmlNodeType.Element) continue;
                var line = li.HasLineInfo() ? li.LineNumber : 0;
                if (defDepth < 0)
                {
                    if (line == startLine || (line >= startLine && reader.Depth == 1)) defDepth = reader.Depth;
                    else continue;
                }
                if (reader.Depth == defDepth) { defDepth = reader.Depth; continue; }
                if (reader.Depth == defDepth + 1) list.Add((reader.Name, line));
                else if (reader.Depth <= defDepth) break;
            }
        }
        catch { /* 解析失败由 RD2001 报告 */ }
        return list;
    }

    private static string ReadManagedDir()
    {
        var env = RimDev.Core.Environment.GameEnvProbe.Discover();
        return env.ManagedDir;
    }
}
```

```csharp
        return i >= 0 && i + 1 < args.Length ? args[i + 1] : null;
    }
```

**已知缺口（诚实列出）**：
1. **`LoadOrderBuilder` 本期未实现** —— 索引只区分「启用 / 全部」，不建立 Core→DLC→activeMods 的严格顺序。影响：`check` 无法判断"哪份同名 def 是胜者"。**理由**：本期不做遮蔽胜者判定，`DuplicateDefNameCheck` 只报"重名"不报"谁遮蔽谁"。第 3 期补。
